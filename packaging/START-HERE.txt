SIMTRAIL TEST KIT
=================

1. Run SimTrail.exe.
   Windows SmartScreen may warn because this test build is not code-signed.
   Choose "More info" and "Run anyway" only if you received this package
   directly from the SimTrail developer.

2. To connect Ansys Workbench 2024 R2:
   - Close Workbench.
   - Open PowerShell in the connector folder.
   - Run:
       .\install_extension.ps1 -AnsysVersion v242
   - Restart Workbench.
   - Enable SimTrailConnector under Extensions > Manage Extensions.

3. SimTrail stores its local SQLite database under the current user's local
   application-data folder. Uninstalling or deleting the portable EXE does not
   delete that database.

4. Result extraction reads existing evaluated scalar results. It does not
   solve models, but it can start Mechanical and consume a Mechanical license.
