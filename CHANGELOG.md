# Changelog

All notable changes to SimTrail will be documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use
[Semantic Versioning](https://semver.org/).

## Unreleased

### Added

- Apache-2.0 licensing and public contribution documentation.
- GitHub issue, pull-request, test, and Windows package automation.
- Public architecture, limitations, and roadmap documentation.

## 0.1.0 - 2026-07-24

### Added

- Local SQLite simulation run register.
- Search, filtering, sorting, comparison, details, and Excel export.
- Workbench project scanning through a persistent local ACT connector.
- Workbench system rename and notes synchronization.
- Existing evaluated scalar-result extraction prototype.
- Portable Windows test package.
